Gilbert Gators: Who's Behind the Mask? — Stage 1 interactive prototype
Open index.html in a browser. Keep map.png in the same folder.
Includes 15 clickable school locations, sample role-based mystery encounters, candy rewards, and browser progress saving.
This is a prototype. The map is fictional and not the real school layout. The Gator is a concept illustration, not yet the official mascot. Staff roles are sample placeholders, not verified staff identities.
For Google Apps Script deployment, the image must be hosted at a public URL and the index HTML must be pasted into an Apps Script HTML file; a Code.gs doGet() can return HtmlService.createHtmlOutputFromFile('Index').
