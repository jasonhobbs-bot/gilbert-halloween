GILBERT GATORS — TEACHER PHOTO REVEALS

WHAT'S NEW
- A teacher's approved photo can now appear after the correct guess and animated mask removal.
- A teacher's real name can replace the demo role in the choices and reveal.
- Existing hallway, joystick, audio, candy score, and lighting fix are preserved.

INSTALL
Upload index.html and teachers.js to the ROOT of your GitHub Pages repository.
Keep any approved photos in a folder named teachers/ and use matching filenames in teachers.js.

HOW TO ADD A TEACHER
1. Obtain permission from the school to use/transform the staff photograph.
2. In teachers.js, enter the teacher's name and photo path for the correct grade.
3. Optionally customize the costume emoji and clue.
4. Upload the edited teachers.js and approved photo to GitHub.

IMPORTANT
- Staff names and photographs are NOT included yet; do not assume permission from the public staff directory.
- The existing 6 doors remain; expanding to 20–25 teachers and 30–40 minutes is a later development stage.
- This package was checked for expected code changes but not tested in a live iPad browser.
